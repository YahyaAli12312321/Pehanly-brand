# PEHANLY - copy-paste API requests

Generated by `node scripts/generate-postman.js` from the live router and the Zod validators.
**201 routes.** Every JSON body below was checked against its real validator.

## How to use

1. Base URL `http://localhost:5000`, prefix `/api/v1`. In Postman create the variables listed in the table at the bottom (or import `postman/PEHANLY.local.postman_environment.json`).
2. Authentication is a **session cookie** (`pl_session`, HttpOnly). There is no bearer token. Postman keeps the cookie automatically after a successful login.
3. Headers for every JSON request: `Content-Type: application/json`. No `Origin` header is needed from Postman.
4. Only one login is active per Postman cookie jar at a time. Logging in as another user replaces the cookie.
5. `{{something}}` values are Postman variables. Replace them with real ids returned by earlier requests (the collection does this automatically through test scripts).
6. Examples are structurally valid. Business rules still apply (a product must exist before it can be ordered, etc.).
